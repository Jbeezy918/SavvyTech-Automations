H MOUNTAIN COMPLETE PROJECT BACKUP

This package contains:

1. deployed-site-source
   The exact editable source recovered from the currently deployed H Mountain
   Retreat website (saved site version 9). It includes the application pages,
   styling, images, booking/checkout prototype, tests, configuration, and
   package lockfile. Dependency folders are intentionally excluded because
   they can be recreated with npm install.

2. library/UPDATED H. MOUNTAIN
   The saved H Mountain planning documents, customer/reference images,
   generated production imagery, design skill notes, and the earlier
   Cloudflare deployment package.

3. library-extra
   The original design comparison image and all recovered standalone HTML
   prototypes.

To place this on a Mac Desktop:

1. Download H-Mountain-Complete-Project.zip.
2. Open Downloads.
3. Drag the ZIP onto Desktop.
4. Double-click it to extract the H-Mountain-Complete-Project folder.

Important:

- The live site source is in deployed-site-source.
- Do not upload the entire backup as a website. Use deployed-site-source.
- No node_modules dependency folder is included.
